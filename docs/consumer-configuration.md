# Consumer Repository Configuration

## Contract

Each consumer repository owns one `agent-skills.json` at its root. This is a Nong Thinh contract, not a native Codex, Claude Code, or Antigravity file.

```json
{
  "$schema": "https://raw.githubusercontent.com/nguyenAnh132/nongthinh-agent-skills/master/schemas/agent-skills.schema.json",
  "schemaVersion": 1,
  "source": {
    "repository": "nguyenAnh132/nongthinh-agent-skills",
    "ref": "01c4a68a43eefca10e76d7f8c9f59bac68924637"
  },
  "skills": [
    "clean-code",
    "code-review"
  ],
  "agents": [
    "codex",
    "claude-code",
    "antigravity"
  ]
}
```

Unknown fields, duplicate entries, unsafe Git references, unsupported agents, and invalid skill names are rejected.

## Fields

### `$schema`

Optional URI reference used by editors for completion and diagnostics. It does not choose the source revision.

### `schemaVersion`

Required integer. Version `1` is the only supported contract version.

### `source.repository`

Required and currently fixed to `nguyenAnh132/nongthinh-agent-skills`. Supporting arbitrary sources would expand the trust boundary and is intentionally out of scope.

### `source.ref`

Required Git branch, tag, or full 40-character commit SHA. Use a commit SHA in normal consumer repositories. Tags are easier to read but can technically be moved; branches always float.

### `skills`

Non-empty array of unique, lowercase kebab-case skill names. Every selected skill must exist and be valid at the resolved source commit.

### `agents`

Non-empty array containing unique values from `codex`, `claude-code`, and `antigravity`.

## Lock File

`agent-skills.lock.json` is generated by the CLI and must not be edited manually. It contains:

- `schemaVersion`;
- requested repository and ref;
- immutable `resolvedCommit` SHA;
- selected skill digests;
- managed target paths, agents, files, and SHA-256 hashes.

Commit the lock file. Normal `sync` respects its commit. `sync --update` re-resolves the configured branch or tag and updates the lock only after a successful synchronization.
